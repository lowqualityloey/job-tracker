# Job Tracker

A starter full-stack portfolio project frontend built with React, TypeScript, Vite, React Router, Vitest, and React Testing Library. This repo is designed as the first stage of a larger project that will later add an ASP.NET Core API, a database, authentication, and AWS deployment.

## Current features

- Responsive dashboard page
- Applications list page
- Application details page
- Typed mock data
- Reusable layout and status badge components
- Antigravity project rules
- Starter test setup with Vitest and React Testing Library

## Tech stack

- React
- TypeScript
- Vite
- React Router DOM
- Vitest
- React Testing Library

## Getting started

```bash
npm install
npm run dev
```

## Run verification

```bash
npm run build
npm run test:run
```
